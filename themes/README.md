Mets ici une image nommee `background.jpg` (ou modifie THEME_BACKGROUND
dans gui_app.py) pour personnaliser le fond de l'application. Sans image,
un fond sombre uni est utilise par defaut.

Ce dossier n'est pas suivi par git (voir .gitignore) : les images de fond
sont un choix personnel, pas partage dans le depot.
